# Gender-Wealth-Analysis
Sample Python scripts for analyzing gendered wealth inequality in historical datasets: demonstrates pandas, matplotlib, and statistical analysis skills.
Sample repository demonstrating data analysis skills for historical wealth inequality research.

## Project Overview
This repository contains sample Python scripts for analyzing gendered wealth distribution using historical datasets. The code demonstrates:
- Data loading and cleaning with pandas
- Descriptive statistics and basic inequality measures
- Data visualization with matplotlib
- Sample analysis workflows applicable to estate inventories and tax registers

## Skills Demonstrated
- Python (pandas, matplotlib, numpy)
- Data cleaning and preprocessing
- Statistical analysis (descriptive stats, percentile analysis)
- Visualization of wealth distribution patterns
